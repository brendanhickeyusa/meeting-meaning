# Changelog

## 1.0.5 — Meeting Meaning preview

- Rename the application and Windows executable to Meeting Meaning.
- Preserve the original local profile so existing keys, transcripts, and glossary remain available.
- Default new installations to Gemini 3.5 Flash-Lite; retain saved model selections.
- Include live microphone/playback transcripts, editable remote speaker labels, local glossary, meeting history, visible meeting dates, and text export.
- Include technical and cybersecurity jargon, acronyms, products, and vendors in term discovery.
- Include model discovery, definition-service diagnostics, detailed error messages, and request limits.

This release does not add general conversation Q&A, answer suggestions, or document retrieval.
